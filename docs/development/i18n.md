# 国际化（i18n）

LumenBridge 内置三语支持（简体中文 / 繁體中文 / English），主程序日志、命令回复、WebUI 前端全部走 i18n。子插件可通过命名空间机制接入同一体系。

## 支持的语言

| 代码 | 语言 | 说明 |
|------|------|------|
| `zh_CN` | 简体中文 | 默认语言 |
| `zh_TW` | 繁體中文 | |
| `en` | English | 回退语言（缺失键的兜底） |

配置项为 `auto` 时按以下优先级自动检测：

1. `server.properties` 的 `language` 字段（标准 Java properties 解析）；
2. Endstone API `server.language.locale`；
3. 兜底 `zh_CN`。

### locale 规范化

`normalize_locale()` 把各种写法归一到支持的代码：

- `zh-CN` / `zh_CN` / `zh-Hans-CN` / `chinese` → `zh_CN`
- `zh_Hant_TW` / `zh-HK` / `zh-MO` → `zh_TW`（脚本子标签 Hans/Hant **优先**于地区判定繁简）
- `en_US` / `en-GB` → `en`
- 不支持的语言（如 `fr_FR`）回退 `zh_CN`

## 主程序翻译

语言包位于 `src/endstone_lumenbridge/locales/{lang}.json`，键为点分层级（如 `plugin.enabled`），支持 `{placeholder}` 占位符：

```json
{
    "_meta": { "native_name": "简体中文" },
    "plugin": {
        "enabled": "LumenBridge 已启用，当前模式：{mode}"
    }
}
```

查找顺序：**当前语言 → en → 键本身**（缺键时显示键名，方便发现漏翻）。占位符格式化失败时原样返回译文，不抛异常。

核心 API：

| 函数 | 说明 |
|------|------|
| `t(key, **kwargs)` | 全局翻译快捷函数 |
| `get_i18n()` | 获取全局 I18n 单例 |
| `i18n.set_language(lang)` | 切换语言（`auto` 保持不变），返回实际生效代码 |
| `i18n.language` / `i18n.lang` | 当前语言代码 |
| `i18n.available_languages()` | 可用语言 `{code: native_name}` |
| `i18n.export(lang=None)` | 导出完整翻译字典（缺失键用 en 补全，供 WebUI 前端使用） |

## 子插件接入翻译

子插件通过**命名空间**注册自己的翻译，卸载时框架自动注销（热重载不泄漏）：

```python
def on_load(lumen):
    lumen.i18n.register_namespace("my_plugin", {
        "zh_CN": {"greeting": "你好，{name}！"},
        "zh_TW": {"greeting": "你好，{name}！"},
        "en": {"greeting": "Hello, {name}!"},
    })
    text = lumen.i18n.tn("my_plugin", "greeting", name="Steve")
```

`tn(namespace, key, **kwargs)` 查找顺序：**命名空间下当前语言 → en → 第一个可用语言 → 键本身**。子插件可以只提供一种语言。

子插件还可以用 `lumen.language` 读取主程序当前生效的语言代码（`auto` 已解析为实际值），据此选择自身文案语言保持统一；前端 iframe 可用公共接口 `GET /api/i18n/current` 获取同一信息。

## WebUI 前端国际化

- WebUI 后端把 `i18n.export()` 的完整字典（en 已补全缺失键）下发给前端；
- 前端按 `data-i18n` 属性等约定替换文案；
- 子插件自定义页面（iframe）可直接复用公共语言接口，无需重复加载主程序语言包。

## 贡献翻译

新增语言或修正词条：

1. 在 `src/endstone_lumenbridge/locales/` 新建/修改 `{lang}.json`（UTF-8，含 `_meta.native_name`）；
2. 在 `i18n.py` 的 `SUPPORTED_LANGUAGES` 登记代码与名称，必要时补充 `_LOCALE_ALIASES` 别名；
3. 词条必须覆盖主语言包全部键，缺失键运行时回退 en，但完整覆盖才能通过 WebUI 语言列表完整展示。
