# LumenBridge v1.0.4 发布说明

> 发布日期：2026-08-29　|　许可证：MIT　|　适用 Endstone 1.21+

本次更新包含两大主题：**子插件配置页面全面升级**（完整复刻 AstrBot 插件配置页风格）与**一轮全面安全审计修复**。所有修复均附带专项回归测试，可直接从 1.0.3 平滑升级。

## 亮点速览

* 子插件配置页焕然一新：分组卡片、搜索过滤、单项恢复默认、未保存拦截

* `ConfigFormBuilder` 新增 4 类字段能力：分组、多选、密码框、滑块

* QQ 官方适配器：断线 Resume 重放消息重复下发修复

* 子插件加载器 4 项健壮性修复（同名冲突 / 热重载保护 / 升级数据保留 / 开关即时生效）

***

## 一、子插件配置页面升级（AstrBot 风格）

子插件配置页面完整复刻 AstrBot 插件配置页的布局与交互风格，同时保留 LumenBridge 现有的视觉主题与全部既有功能。

### 全新布局

* **分组嵌套卡片**：子插件可通过 `section()` 声明配置分组，渲染为嵌套卡片形成层级感

* **两列行式布局**：左侧字段名 + 描述、右侧控件，窄屏（手机端）自动退化为上下堆叠

* **配置项数量徽章**：弹窗标题栏实时显示当前配置项总数

### 全新交互

| 特性     | 说明                                        |
| ------ | ----------------------------------------- |
| 搜索过滤   | 顶部搜索框按 key / label / desc 模糊匹配，无命中的分组整组隐藏 |
| 单项恢复默认 | 当前值 ≠ 默认值的字段右侧出现恢复按钮，一键回填默认值              |
| 全部恢复默认 | 底部一键恢复全部字段（带二次确认）                         |
| 未保存拦截  | 任意输入即标记「未保存的更改」（底部脉冲徽章），关闭弹窗前弹出确认         |
| 快捷保存   | 配置弹窗打开时支持 Ctrl / Cmd + S 快捷保存             |
| 批量导入   | array 字段支持按行批量导入，逐项去重                     |
| 全屏编辑   | textarea 字段右上角提供全屏编辑弹窗                    |

### ConfigFormBuilder API 扩展

子插件配置表单构建器新增以下能力：

**新增字段方法**

```python
builder.section("基本设置", "触发与输出行为")          # 分组卡片
builder.multiselect("events", ["join"], OPTIONS)      # 多选复选框组
builder.text("token", val, secret=True)               # 密码框（带明文切换）
builder.number("interval", 30, minimum=10, maximum=300, step=5)  # 滑块联动
```

**通用可选参数**（除 `file` 外所有字段支持）

| 参数             | 说明                               |
| -------------- | -------------------------------- |
| `default`      | 显式默认值；未声明时以注册时初始值为默认，作为「恢复默认」数据源 |
| `obvious_hint` | 标记重要配置项，字段名旁显示 ‼️                |
| `show_key`     | 在字段名旁以等宽字体显示配置键名                 |

**其它控件升级**

* `array` 字段升级为 chips 列表编辑器（逐项增删 + 批量导入）

* `select` 字段改用自定义下拉组件（带搜索），options 由后端统一规范化

详细用法见《LumenBridge 子插件开发文档》「配置表单」章节。

## 二、审计修复

本轮对框架核心模块做了一次全面审计，以下问题均已修复并附带专项回归测试（`tests/test_audit_fixes.py`）。

### QQ 官方机器人适配器

* **断线 Resume 重放消息重复下发**：网关断线重连（Resume 补投）期间，官方会重放已处理过的 seq 事件，旧逻辑会重复下发消息导致机器人复读。现按 seq 去重，重放事件直接丢弃，新事件正常放行

* **msg\_id 过期被动凭据堆积（错误码 40034005）**：官方判定 msg\_id 过期后，被动凭据池中的过期条目现在会被及时清理，并自动剥离过期凭据字段改走主动通道重试，消息不再发送失败

* **会话失效关闭码处理**：网关 op=9（无效会话）时 seq 归零并走全新 Identify 重连，不再携带失效会话反复被拒

### 子插件加载器

* **同名子插件冲突**：两个目录的清单声明同一插件名时，仅先加载者生效，后者明确拒绝（原先行为未定义）

* **热重载保护**：`reload_one` 现在先校验新清单再卸载旧实例——清单损坏（非法 JSON）或 `load: false` 时直接返回失败，**运行中的实例不再被误卸载**

* **升级数据保留**：子插件升级时递归保留全部嵌套目录中的用户数据（如 `data/nested/state.json`、`config/settings.json`），仅替换代码文件

* **开关即时生效**：WebUI / 命令启用、禁用子插件立即加载或卸载运行实例（原先仅改写清单，需重启或手动重载）

### 正则引擎

* **非法动作元素跳过**：规则文件中含未知 / 格式错误的动作元素时跳过该项并记录日志，不再中断整条规则执行

### 插件市场

* **清单检查时间原子写入**：更新检查时间戳改为临时文件 + 替换的原子写入，进程中断不再留下 `.json.tmp` 残留或损坏的清单

### 配置页自身

* **批量导入面板无法展开**：显隐 CSS 规则误写在 textarea 上而非包裹容器，已修正（本版本内测发现并修复）

1. WebUI「框架更新」或上传 `endstone_lumenbridge-1.0.4-py3-none-any.whl` 执行更新
2. 热重载生效（注意：热重载会重载服务器内全部插件，建议低峰期操作）
3. 无破坏性变更：已有子插件配置表单无需改动即可继续工作，新字段能力按需使用
